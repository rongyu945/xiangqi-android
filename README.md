# 中国象棋 1.3.0（离线版）

中国象棋单机游戏（人机对战 + 双人模式），离线 HTML 转安卓 APK（WebView 壳工程）。
游戏本体是**单文件 HTML**，双击即可在浏览器里玩，也可以打包成安卓 App。

## 📦 安装包

- [`apk/中国象棋-1.3.0.apk`](apk/中国象棋-1.3.0.apk) —— 安卓安装包（安卓 5.0+，ARM64）
- Release 页面的 `xiangqi-1.3.0.apk` 是同一个文件
- 首次安装自签名 APK 需允许「未知来源」，选「仍要安装」

## ✨ 功能

### 对局
- **执棋选择**：执红 / 随机 / 执黑（滑块式切换）；执黑时黑棋在下方、红方(AI)先手
- **双人模式**：面对面各看一侧，对面棋子自动翻转 180°；**双方各有独立悔棋按钮**（对方那侧按钮倒置显示），每方固定 3 次悔棋，只有刚走完棋的那一方能悔，对方的悔棋提示按座位翻转方向
- 悔棋（人机模式按难度限次：简单10 / 困难7 / 大师3）、新对局、认输
- 3 档难度：简单 / 困难 / 大师
- **安卓返回键**：设置面板、弹窗、选题列表开着时，返回键先关它们，都没有才退出

### 界面
- **精细设置面板**：长按顶部标题唤出（隐形入口）
  - **深色模式**（棋盘保留木色只整体调暗，棋子配色不变）
  - **声音效果**开关
  - **需要提示**开关（开启后棋盘右下角出现灯泡按钮，点它用 AI 深度 3 搜索替你想一步，起点画框、终点高亮）
  - **练习模式**开关
- 作者署名：设置面板内「作者：戎昱」
- **走棋记录**：可折叠；逐手中文记谱，有复盘评价时可点击任一手查看那一手的分析
- **楷体棋子**：棋子文字用内嵌楷体字（帥仕相傌俥炮兵將士象馬車砲卒 14 字全部内嵌），手机上肯定显示楷书
- 立体渐变棋子 + 阴影 / 滑动走子动画 / 四套音效（落子 / 吃子 / 将军 / 终局）

### 练习模式（残局题库，18 题 / 6 组）
点面板上的题名可打开**选题列表**直接跳题，面板支持「上一题 / 重试 / 下一题」。

| 组 | 题目 | 步数上限 |
|---|---|---|
| 基本杀法 | 单马擒孤将 / 单车例胜单缺士 / 炮镇当头·铁门栓 / 双车错杀 | 30 / 40 / 3 / 3 |
| 一步杀 | 马后炮 / 车炮抽杀 / 重炮杀 / 闷宫杀 | 1 / 1 / 1 / 1 |
| 两步杀 | 卧槽马 / 车马冷着 / 双炮叠杀 / 车兵巧胜 | 2 / 2 / 2 / 2 |
| 三步杀 | 三步收网 / 车炮三手杀 | 3 / 3 |
| 实用残局 | 单兵巧胜单士 / 马低兵胜单士 / 车兵必胜士象全 / 炮双兵士相全 | 25 / 30 / 50 / 45 |

- 达成目标（将杀）或超出步数会弹窗结算，可重试或进入下一题
- 战术题的步数上限就是最少步数，逼你找最短杀法
- 练习模式固定人机对练：自动隐藏执色滑块、置灰「双人模式」、「认输」变成「放弃本题」

### 界面→AI 增强（1.3.0 新增）
- **开局库**：内置 3 套经典开局定式（中炮对屏风马 / 顺炮 / 仙人指路），AI 开局按棋谱走标准应对（如对方起中炮，AI 会正常跳马/上象不再随手平炮），开局谱走完自动交回引擎，不影响中残局
- **位置评估 PST**：评估函数使用 Piece-Square Table（位置价值表，源自 UCLA 2008 棋盘学习论文），棋子每格的位置价值细化，替代早期简单的手写中心性修正——AI 的进攻方向感和子力运用更合理

## 🧠 AI 与记谱

- **中文记谱**：标准中式记谱（如「炮二平五」「马8进7」），红黑各自以己方列号计，走棋记录逐手记录、点击任一手可回味/回溯复盘
- **搜索**：α-β 剪枝 + 迭代加深（逐层加深，到时间预算就提前收手，绝不返回空着法）、
  Zobrist 哈希 + 置换表（TT，上限 20 万条，存上下界可作为历史着法引导排序）、
  根节点与内节点按「吃子分值」排序着法（先搜吃大子），静态搜索（quiescence）保证吃子链不被截断
- **难度**：差异由「搜索深度 + 时间预算 + 可接受着法质量(margin)」共同决定，
  弱化方式是在「与最佳着法差距不超过 margin」的合格着法里随机挑次优，而不是靠允许 AI 走坏棋
  - 简单 2 层 / 0.4 秒 / margin90（额外加送子保护：不吃亏不吃无补偿的送子着法）、
    困难 3 层 / 0.9 秒 / margin35、大师 5 层 / 3 秒 / margin0
- **规则**：将杀 / 困毙（无子可动）即终局，AI 不会走送将的非法着法

## 🏗️ 从源码构建

需要 JDK 21 + Android SDK 34 + Gradle 8.x：

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
export ANDROID_HOME=$HOME/android-sdk
export PATH="/opt/homebrew/opt/gradle@8/bin:$JAVA_HOME/bin:$PATH"
gradle assembleRelease --no-daemon
# 产物：app/build/outputs/apk/release/app-release.apk
```

> 说明：`release.keystore` 为本地签名密钥，出于安全未纳入版本控制，构建请在本地生成同 alias 的 keystore。
