# 中国象棋 1.7.1（离线版）

中国象棋单机游戏（人机对战 + 双人模式），离线 HTML 转安卓 APK（WebView 壳工程）。
游戏本体是**单文件 HTML**，双击即可在浏览器里玩，也可以打包成安卓 App。

## 📦 安装包

- [`apk/中国象棋-1.7.1.apk`](apk/中国象棋-1.7.1.apk) —— 安卓安装包（安卓 5.0+；无原生库，各 CPU 架构通用）
- Release 页面的 `xiangqi-1.7.1.apk` 是同一个文件
- 首次安装自签名 APK 需允许「未知来源」，选「仍要安装」

## ✨ 功能

### 对局
- **执棋选择**：执红 / 随机 / 执黑（滑块式切换）；执黑时黑棋在下方、红方(AI)先手
- **双人模式**：面对面各看一侧，对面棋子自动翻转 180°；**双方各有独立悔棋按钮**（对方那侧按钮倒置显示），每方固定 3 次悔棋，只有刚走完棋的那一方能悔，对方的悔棋提示按座位翻转方向
- 悔棋（人机模式按难度限次：简单 10 / 困难 7 / 大师 3）、新对局、认输
- 3 档难度：简单 / 困难 / 大师
- **续下存档**：每走完一步（含 AI 应招、悔棋之后）就把棋局落进本地存档，App 关掉（含安卓后台杀掉）再打开自动接着下。
  恢复前会先做数据体检（版本号、10×9 格子、棋子值域、双方各有一将），坏档一律丢弃并开新局，绝不半崩。
  新对局 / 换颜色 / 切模式 / 认输 / 练习模式仍会作废存档，行为不变。
- **安卓返回键**：设置面板、弹窗、选题列表开着时，返回键先关它们，都没有才退出

### 界面
- **精细设置面板**：长按顶部标题唤出（隐形入口）
  - **深色模式**（棋盘保留木色只整体调暗，棋子配色不变）
  - **声音效果**开关
  - **需要提示**开关（开启后棋盘右下角出现灯泡按钮，点它用引擎替你想一步，起点画框、终点高亮）
  - **练习模式**开关
- 作者署名：设置面板内「作者：戎昱」
- **走棋记录**：可折叠；逐手中文记谱，有复盘评价时可点击任一手看那一手的分析（最佳 / 好棋 / 疑问手 / 失误）
- **楷体棋子**：棋子文字用内嵌楷体字（帥仕相傌俥炮兵將士象馬車砲卒 14 字全部内嵌），手机上肯定显示楷书
- 立体渐变棋子 + 阴影 / 滑动走子动画 / 四套音效（落子 / 吃子 / 将军 / 终局）
- 双人模式下自动隐藏「执色滑块」与难度档（同机轮流走棋，选了也没用）

### 练习模式（残局题库，18 题 / 5 组）
点面板上的题名可打开**选题列表**直接跳题，面板支持「上一题 / 重试 / 下一题」。

| --- | --- | --- |

| 一步杀 | 马后炮 / 车炮沉底杀 / 双炮杀 / 车杀闷宫 | 1 / 3 / 1 / 1 |
| 两步杀 | 车马两步杀 / 车马冷着 / 双炮两步杀 / 车兵巧胜 | 2 / 2 / 2 / 2 |

| 实用残局 | 单兵巧胜单士 / 马低兵胜单士 / 车兵必胜士象全 / 炮双兵士相全 | 25 / 30 / 50 / 45 |

- 达成目标（将杀）或超出步数会弹窗结算，可重试或进入下一题
- 战术题的步数上限就是最少步数，逼你找最短杀法
- 练习模式固定人机对练：自动隐藏执色滑块、置灰「双人模式」、「认输」变成「放弃本题」、不进对局存档
- 全部 18 题都经真实引擎穷搜 / 自对弈验证过（1.6.6 起重做了 9 题：原先 18 题里有 6 题局面非法或限步内无解）

## 🧠 AI 与规则

- **中文记谱**：标准中式记谱（如「炮二平五」「马8进7」），红黑各自以己方列号计，走棋记录逐手记录、点击任一手可回看那一手的复盘评价
- **搜索**：α-β 剪枝 + 迭代加深（按实测的逐层耗时增长预测下一层算不算得完，绝不白等到预算耗尽、也绝不返回空着法）、
  Zobrist 增量哈希 + 置换表（53 位双哈希、平铺 Int32Array、上限 20 万条，满表时丢弃较旧的一半而不是整表清空）、
  历史启发着法排序、空着剪枝、将军延伸、静态搜索（quiescence，吃子链不被截断）、根层跨步重复过滤
- **Web Worker 搜索**：引擎跑在 Worker 里，AI 思考时界面照常流畅；Worker 失败 / 超时（简单·困难 3 秒、大师 6 秒）会终止并重建，
  再不行回退主线程同步搜索（限时 1.2 秒），最后兜底走第一个合法着法 —— 不会出现「AI 卡住不下棋」
- **评估**：子力 + 位置价值表（PST，源自 UCLA 2008 棋盘学习论文）
- **规则判定**：
  - 将杀 / 困毙（无子可动）即终局，AI 不会走送将的非法着法
  - **无效长将判负**：连续将军且局面没有实质进展（局面重复）判负；有效的连将追杀（局面在推进）不判负
  - **三次重复判和**：同一局面第三次出现即判和
  - **子力判和**：双方都无进攻子力（车 / 马 / 炮 / 过河兵）时判和
- **难度**：差异由「搜索深度 + 时间预算 + 可接受着法质量(margin)」共同决定，
  弱化方式是在「与最佳着法差距不超过 margin」的合格着法里随机挑次优，而不是靠允许 AI 走坏棋
  - 简单 2 层 / 0.4 秒 / margin90（另加送子保护：margin 池内剔除会丢大子且无补偿的着法）
  - 困难 3 层 / 0.9 秒 / margin35
  - 大师 上限 10 层 / 3 秒 / margin0（迭代加深用到时间为止；1.7.0 实测交替执色对局，新版执黑平均存活 24.8 → 34.9 步）

## 🏗️ 从源码构建

需要 JDK 21 + Android SDK 34 + Gradle 8.x：

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
export ANDROID_HOME=$HOME/android-sdk
export PATH="/opt/homebrew/opt/gradle@8/bin:$JAVA_HOME/bin:$PATH"
gradle assembleRelease --no-daemon
# 产物：app/build/outputs/apk/release/app-release.apk
```

> 说明：`release.keystore` 为本地签名密钥，出于安全未纳入版本控制，构建请在本地生成同 alias 的 keystore。
